# AICTE KOSH-Rakshak Official User Manual

## 1. Introduction
This manual provides standard operating procedures for educational institutional heads, regional regulatory officers, bank managers, and AICTE executive directors.

---

## 2. Institutional College Nodal Officer Guide
1. **Login**: Access the portal at `http://localhost:5173/`, select `Institutional Nodal Officer (College View)`, and enter credentials.
2. **Deposit Portfolio**: Review current status, statutory deficit calculations under APH Table 4.1, and upcoming lock-in maturity dates.
3. **FDR Intake**: Drop the scanned PDF/JPEG certificate into the drag-and-drop zone. Review OCR auto-filled fields and confirm.
4. **Renewal Submission**: If an instrument is within 60 days of expiry, submit the replacement FDR link to guarantee 0-day coverage continuity.
5. **Release Petition**: Once the 8-year lock-in tenure completes, submit a release petition to track real-time clearance across all 5 gates.

## 3. Regional Scrutiny Officer Guide
1. **Master Submission Queue**: View all pending submissions within jurisdictional oversight (e.g., SRO Chennai / NRO Kanpur).
2. **Forensic Studio**: Inspect Error Level Analysis (ELA) pixel heatmaps, verify compounding math formula compliance, and review NLP loophole alerts.
3. **Dual-Source Green Sheet Registry**:
   - Compare College Claimed vs AI OCR vs Bank CBS Confirmation in the compact registry table.
   - Click `"Review & Sign"` to auto-scroll to the note sheet desk.
   - Select Recommended Action (`Approve`, `Hold`, `Alert`, `Sanction`).
   - Digitally sign and dispatch the official memo via NIC e-Token.
4. **Validity Monitor**: Review automated Tier-1, Tier-2, and Tier-3 default notices dispatched to institutions.
5. **Audit Ledger**: Verify block-by-block cryptographic SHA-256 chain integrity for jurisdictional actions.
